# Google-Play-Store-Analysis---Through-Python-
Google play Store Analysis by Null class

Google Play Store Data Analysis:
The planned project analyzes Google Play Store data for checking app performance, user ratings, category trends, and customer sentiment. Process involves data cleaning, visualization, and sentiment analysis through Python libraries.

Key Features
Cleaning and Preprocessing of Data: Data duplicates, missing values are removed.
EDA: Various app categories were utilized for the depiction of installs, ratings, and reviews.
Sentiment Analysis: NLTK was used for analyzing user reviews in terms of positive, neutral, and negative sentiment.
Interactive Charts: The charts generated by Plotly for a more dynamic and clear visual representation.

Insights Derived:
 - Most popular app categories with the maximum installs.
- The correlation between rating and the number of reviews.
- The change in user sentiment over time for the top apps.

Tech Stack
Language: Python
Libraries: pandas, numpy, plotly, nltk, scikit-learn
Data Set: Google Play Store Apps Data (Play Store Data.csv) & User Reviews (User Reviews.csv)

How to Run
Prerequisites: Ensure that Python 3.8+ is installed on your system along with the required packages:
pip install pandas numpy plotly nltk scikit-learn matplotlib

Run the Notebook:
Open Jupyter Notebook and run all cells one after another:
jupyter notebook anaylsis.ipynb

Execution Time:
The whole execution will take approximately 3 to 5 minutes (to load data, clean, and produce all charts).

View Results:
The notebook will display the following:

- Install distribution based on categories
- Correlation between rating and review
- Visualizations for sentiment analysis
- Insights regarding user engagement and app success

Dataset
- PlayStoreData.csv: It is a file containing the app-related details such as ratings and installs.
- User Reviews.csv: It contains the text of user comments and their corresponding sentiment data.
